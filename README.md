# نظام الحضور — النسخة المحلية (Desktop)

نسخة تشتغل بالكامل على جهاز السنتر، من غير إنترنت (إلا وقت إرسال تنبيه تليجرام)، ومن غير أي اشتراك شهري.

## التشغيل (للتجربة على جهازك)

```bash
pip install -r requirements.txt
python app.py
```

بعدها افتحي المتصفح على: `http://127.0.0.1:5000`

## إضافة الطلاب

افتحي `seed_students.py`، زوّدي أسماء وأكواد باقي الطلاب في قايمة `STUDENTS`، وشغّلي:

```bash
python seed_students.py
```

## تفعيل تنبيهات تليجرام (اختياري)

1. اعملي بوت جديد عن طريق `@BotFather` في تليجرام، وهتاخدي منه **Token**
2. حطي التوكن في `app.py` داخل `TELEGRAM_BOT_TOKEN`
3. لكل ولي أمر، لازم تعرفي **chat_id** بتاعه (فيه طرق بسيطة تتبحث عنها بـ "how to get telegram chat id")، وتحطيه في `TELEGRAM_CHAT_IDS`

## تحويله لبرنامج .exe (يشتغل بدبل كليك من غير Python)

```bash
pyinstaller --onefile --add-data "static;static" app.py
```

الملف النهائي هيطلع في فولدر `dist/app.exe` — ده اللي بيتسلّم للسنتر، يحطوه على أي جهاز ويشتغل مباشرة.

## قاعدة البيانات

كل البيانات (الطلاب + سجل الحضور) في ملف واحد اسمه `attendance.db` بيتعمل تلقائي أول ما تشغّلي `app.py`. عايزة تعملي نسخة احتياطية؟ انسخي الملف ده بس.

## التقارير الشهرية

اطلبي من المتصفح:
```
http://127.0.0.1:5000/api/report?month=2026-08
```
هيرجعلك كل سجلات الحضور للشهر ده بصيغة JSON — لو عايزة تطلعيها Excel/PDF بشكل منظم، قولي لكلود يبنيلك زرار "تصدير التقرير" في الواجهة.
